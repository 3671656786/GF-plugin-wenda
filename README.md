## 是什么

在群聊 / 私聊里维护「问题 → 答案」词库，支持：

- **精准问答**：消息全文与问题完全一致才命中
- **模糊问答**：消息里包含问题关键词即命中
- **延时问答**：命中后延迟指定秒数 / 毫秒再回复
- **三个范围**：本群、全局、私聊，全局优先
- **回复模式**：带艾特 / 纯文本，支持全局 / 本群 / 私聊独立设置
- **单条答案级控制**：可为单条答案指定是否带艾特
- 答案可为纯文字、纯图，或文字 + 图片
- 可选：命中答复 / 列表 / 添加预览后按秒数自动撤回

插件载入后匹配即开启，**没有**单独的「开关问答」指令。

## 使用前准备

1. 将成品目录 `GF-plugin-wenda/` 放入 Kakake 的 `plugins/`。
2. 在 Kakake 后台启用 / 重载本插件。
3. 打开本插件配置，填写 **固定操作者 OpenID**。  
   当前代码默认值为：

   ```text
   6E0B188704AC0611617425B687DB9034
   ```

   注意：这不是 QQ 号，而是官方机器人的 `user_openid`。  
   建议部署后改成你自己的 OpenID。

4. 可选配置：
   - **机器人 OpenID**：填写后，列表里的「测试问答」按钮会填入 `@机器人 问题`
   - **全局回复带艾特**：默认开启
   - **私聊回复带艾特**：默认开启

5. 群聊中发管理指令时，通常需要 **@机器人**，以你机器人在开放平台的收消息设置为准。

未配置固定操作者时，会使用代码内置默认值 `6E0B188704AC0611617425B687DB9034`。

## 权限说明

| 能力 | 谁能用 |
|------|--------|
| 发送 `问答菜单` / `问答帮助` / `问答指南` | 所有用户 |
| 发送 `问答词列表` 查看本群问答 | 所有用户 |
| 触发已配置的问答 | 所有用户 |
| 发送 `我的账号` 查询自己的 OpenID | 所有用户 |
| 打开 `问答系统` 管理菜单 | 主人，或本群群主 / 管理员 |
| 主人管理：加主人 / 删主人 / 查看主人列表 / 清空主人 | **仅固定操作者** |
| 本群问答、本群延时问答、本群撤回时间、切换本群回复模式 | 主人，或本群群主 / 管理员 |
| 全局 / 私聊词库、清空全部、全局 / 私聊撤回时间、切换全局 / 私聊回复模式 | **仅主人** |
| 清空全部精准 / 模糊问答 | **仅主人** |

这里的“主人”包括：

1. 配置项 `ownerOpenId` 指定的 **固定操作者**
2. 通过 `加主人` 加入 `masters` 列表的 **其他主人**

固定操作者还可以管理主人列表；其他主人不能打开主人管理板块。

无权限时：

- 普通管理指令多数 **静默忽略**。
- 部分菜单 / 板块会提示无权限。
- 普通用户发送 `问答系统` 会提示：

  ```text
  你没有管理权限哦～
  如需查看问答使用说明，请发送：
  问答菜单
  ```

## 指令前缀 `/`

所有**管理指令**都支持在开头加一个 `/`（全角 `／` 也可以），效果与不加一样：

| 不加前缀 | 加前缀（等价） |
|----------|----------------|
| `问答系统` | `/问答系统` |
| `添加精准问答#你好#你好呀` | `/添加精准问答#你好#你好呀` |
| `问答词列表#1` | `/问答词列表#1` |
| `删除全局模糊问答#关键词` | `/删除全局模糊问答#关键词` |

- 前缀只在**指令最开头**生效。
- 普通问答的**命中匹配**仍按词库里配置的问题原文比较，不会自动去掉 `/`。
- 问答词本身带不带 `/`，就按原样匹配。

## 单个答案艾特控制

格式：在添加问答时，答案末尾加 `#N@` 或 `#Y@`。

| 后缀 | 含义 |
|------|------|
| `#N@` | 该条答案纯文本回复，无艾特、无响应用时 |
| `#Y@` | 该条答案带艾特回复，带蓝色艾特和响应用时 |
| 不加后缀 | 使用所在范围的默认回复模式 |

示例：

| 指令 | 效果 |
|------|------|
| `添加精准问答#你好#你好呀` | 使用本群默认模式 |
| `添加精准问答#你好#你好呀#N@` | 强制纯文本 |
| `添加精准问答#你好#你好呀#Y@` | 强制带艾特 |
| `添加延时精准问答#晚安#好梦#60#N@` | 延迟 60 秒 + 强制纯文本 |
| `添加延时毫秒精准问答#上号#开黑#5000#Y@` | 延迟 5000 毫秒 + 强制带艾特 |

`#N@` / `#Y@` 会被解析器剥离，不会出现在答案内容里。

## 回复模式

| 指令 | 说明 | 权限 |
|------|------|------|
| `切换全局回复模式` | 全局默认模式切换 | 仅主人 |
| `切换本群回复模式` | 本群默认模式切换 | 主人 / 群主 / 管理员 |
| `切换私聊回复模式` | 私聊默认模式切换 | 仅主人 |

模式说明：

- **带艾特**：回复时顶部会 `<@用户 openid>`，并追加 `> 响应用时: xxxms`
- **纯文本**：回复时直接输出答案，不带艾特，不带响应用时

优先级：

1. 单条答案的 `#N@` / `#Y@` 后缀，最高优先
2. 所在范围的回复模式：本群 / 私聊
3. 全局回复模式，兜底

## 添加规则

- 普通格式：`添加…问答#问题#答案`
- 延时秒格式：`添加延时…问答#问题#答案#秒数`
- 延时毫秒格式：`添加延时毫秒…问答#问题#答案#毫秒数`
- 答案可为空字符串，但必须另附图片，否则提示答案不能为空。
- 同一范围、同一类型下，问题已存在则不能覆盖；请先删除再添加。
- 菜单蓝字点「设置…撤回时间」时，填入框默认是 `#115`，可改。
- 添加图片时，插件可能将图片上传到第三方图床。

## 匹配顺序

**范围优先**：

- 群聊：先查 **全局**，再查 **本群**。
- 私聊：先查 **全局**，再查 **私聊**。

**同一范围内类型顺序**：

1. 精准普通
2. 模糊普通
3. 延时精准（秒）
4. 延时模糊（秒）
5. 延时毫秒精准
6. 延时毫秒模糊

命中后：

- 若为延时类，先等待指定时间，再发送。
- 若为普通类，立即发送。

回复格式：

- 带艾特模式：

  ```text
  <@用户 openid>
  答案内容…
  > 响应用时: xxms
  ```

- 纯文本模式：

  ```text
  答案内容…
  ```

管理菜单、列表、添加预览等管理类回复，通常会带 `> 响应用时`，群聊中还会 @ 用户。

## 列表与测试问答

- `问答词列表` / `详细问答词列表` 支持 `#页码`。
- 普通用户群聊中可查看本群问答；主人 / 群管可查看有权限的全局、私聊、本群等类型。
- 只显示非空类型，空库不占块。
- 每页预算：可见类型数 × 3 格。
- 一张图占 1 格；正文约每 4 行占 1 格；多出的格会挤占本页后面类型的条目。
- 问题是蓝字：点一下会填入对应的「删除…#问题」，回车即可删除。
- 每条问答下方会有一个 `测试问答` 蓝字按钮：
  - 配置了 `botOpenId`：填入 `@机器人 问题`
  - 未配置：只填入问题文本，需要手动 @ 机器人
- 有上一页 / 下一页时，底部会出现翻页蓝字。

## 答案撤回

菜单蓝字：`设置本群/全局/私聊答案撤回时间#120`，点进去默认填 `#115`。

| 秒数 | 含义 |
|------|------|
| `0`，默认 / 未配置 | 不撤回 |
| `1`～`600` | 成功输出后倒计时撤回本次机器人发出的答案类消息 |
| 缺参、非整数、超出 0～600 | 警告，不写盘 |

会按撤回时间处理的输出：

- 正式命中答复：用命中词库对应范围的秒数，全局 / 本群 / 私聊
- 问答词列表、添加成功后的预览：用当前聊天场景，群聊用本群秒数，私聊用私聊秒数
- 延时问答命中后，也按命中范围秒数撤回

不会自动撤的：

- 菜单本身
- 设置成功提示
- 超范围警告
- 删除 / 清空确认等

说明：官方对机器人自发言消息的可撤窗口往往约 2 分钟；配到更长时，超时失败只记日志，不打扰群聊。

## 数据存储

配置保存在插件配置文件中，包含：

- `ownerOpenId`
- `masters`
- `botOpenId`
- `replyAtGlobal`
- `replyAtPrivate`
- `replyAtGroups`

问答数据保存在机器人账号对应的数据目录中：

```text
data/问答系统/
  ├─ 全局/
  │   ├─ 精准.json
  │   ├─ 模糊.json
  │   ├─ 延时精准.json
  │   ├─ 延时模糊.json
  │   ├─ 延时毫秒精准.json
  │   └─ 延时毫秒模糊.json
  ├─ 私聊/
  │   └─ ...
  ├─ <群目录>/
  │   └─ ...
  ├─ 撤回时间.json
  └─ 图片数据/
      └─ urls.json
```

当前代码的延时问答主要写入本群目录。

## 常见问题

**发了管理指令没反应？**  
多半无权限。核对固定操作者 OpenID、主人列表，或确认你是本群群主 / 管理员。普通成员可发送 `问答菜单` 查看说明。

**加了问答却命中不了？**  
检查是精准还是模糊；精准要求全文一致，去掉 @ 后比较。全局可能先命中了别的词。

**列表里没有某类型？**  
该类型为空则不显示。普通用户只能看本群问答；私聊普通用户通常无输出。

**想改已有答案？**  
先删除对应问题，再添加。

**延时问答添加后没反应？**  
请确认：

1. 是否在群聊中操作，当前代码延时问答只在本群生效
2. 命令格式是否正确
3. 秒数 / 毫秒数是否合法：秒 1～60，毫秒 1～60000
4. 发送 `问答词列表` 是否能看到对应条目

**单个答案的 `#N@` 后缀显示在答案内容里？**  
请确认插件版本为 v1.2.0 或更高。

**回复模式切换后不生效？**  
优先级：单条答案后缀 > 本群 / 私聊模式 > 全局模式。

**默认固定操作者 OpenID 是多少？**  
当前代码默认是：

```text
6E0B188704AC0611617425B687DB9034
```

不是旧文档里写的 `7014ACA9441AF768BC9E9D5EED7EAE9B`。

**全局延时问答在哪里？**  
当前 `index.mjs` 没有全局 / 私聊延时添加分支，延时问答仅本群群聊可用。
