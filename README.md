# 问答系统 · 使用说明（QQ 官方机器人）

> 版本：**1.1.0** · 插件目录：`GF-plugin-wenda` · 显示名：问答系统 · 原作者：三个句号，二改作者：天道化逍遥

本插件走 **kakake GF 官方车道**（目录名须为 `GF-` 前缀），对接 QQ 开放平台机器人，**不是** OneBot / NapCat 野生协议。

---

## 📢 版本更新日志

**v1.1.0（当前版本）新增：**

- ✅ **延时问答（秒）**：答案延迟 1～60 秒回复
- ✅ **延时毫秒问答**：答案延迟 1～60000 毫秒回复
- ✅ **单个答案艾特控制**：通过 `#N@` / `#Y@` 后缀，为单条答案指定是否带艾特
- ✅ **回复模式分板块**：全局 / 本群 / 私聊三种独立的默认回复模式，互不干扰
- ✅ **普通用户专属菜单**：新增 `问答菜单` / `问答帮助` / `问答指南` 指令，供无权限用户查看
- ✅ **问答词列表全员开放**：任何用户均可查看本群问答
- ✅ **管理菜单权限收紧**：`问答系统` 指令仅主人/群主/管理员可打开
- ✅ **修复 `content` 字段为空的已知问题**

## 是什么

在群聊 / 私聊里维护「问题 → 答案」词库，支持：

- **精准问答**：消息全文与问题完全一致才命中
- **模糊问答**：消息里包含问题关键词即命中
- **延时问答**：命中后延迟指定秒数 / 毫秒再回复
- **三个范围**：本群、全局、私聊（全局优先）
- **回复模式**：带蓝色艾特 / 纯文本，支持全局 / 本群 / 私聊独立设置
- **单条答案级控制**：可为单条答案指定是否带艾特
- 答案可为纯文字、纯图，或文字 + 图片
- 可选：命中答复 / 列表 / 添加预览 后按秒数自动撤回

插件载入后匹配即开启，**没有**单独的「开关问答」指令。

## 使用前准备

1. 将成品目录 `GF-plugin-kaka/` 放入 Kakake 的 `plugins/`（官方连接会再复制到对应账号的运行目录）。
2. 在 Kakake 后台启用 / 重载本插件。
3. 打开本插件配置，填写 **最高主人 openid**（官方机器人的 `user_openid`，不是 QQ 号）。默认值为 `7014ACA9441AF768BC9E9D5EED7EAE9B`。
4. 可在配置面板设置：
   - **主人 OpenID**（默认值已内置）
   - **全局回复带艾特**（默认开启）
   - **私聊回复带艾特**（默认开启）

未填写主人时：全局 / 私聊管理指令无人可用；本群仍可由群主 / 管理员管理。

群聊中发指令时，通常需要 **@机器人**（以你机器人在开放平台的收消息设置为准）。

## 快速上手

1. 有权限的人在群里发：`问答系统`（可先 @ 机器人）。
2. 点菜单蓝字：会把指令填进输入框，改完再发。
3. 例如添加本群精准：`添加精准问答#你好#你好呀`
4. 之后任何人发 `你好`（精准）或包含关键词的句子（模糊），机器人会按词库回复。

**普通用户**：发送 `问答菜单` 查看使用说明，发送 `问答词列表` 查看本群问答。

| 指令 | 说明 | 权限 |

| `问答菜单` / `问答帮助` / `问答指南` | 查看普通用户使用指引 | 所有人 |

列表规则简述：

- 普通用户只会看到 **本群问答**；主人/管理员可看到全局、私聊、本群以及各类延时问答。
- 只显示 **非空** 的类型（空库不占块）。
- 每页预算：可见类型数 × 3 格；一张图占 1 格；正文约每 4 行占 1 格；多出的格会 **挤占** 本页后面类型的条目。
- 问题是蓝字：点一下会填入对应的「删除…#问题」，回车即可删除。
- 有上一页 / 下一页时，底部会出现翻页蓝字。

## 🆕 单个答案艾特控制

**格式**：在添加问答时，答案末尾加上 `#N@` 或 `#Y@`：

| 后缀 | 含义 |
|------|------|
| `#N@` | 该条答案 **纯文本** 回复（无艾特、无响应用时） |
| `#Y@` | 该条答案 **带艾特** 回复（蓝色艾特 + 响应用时） |
| 不加后缀 | 使用所在范围的默认回复模式 |

**示例**：

| 指令 | 效果 |
|------|------|
| `添加精准问答#你好#你好呀` | 使用本群默认模式 |
| `添加精准问答#你好#你好呀#N@` | 强制纯文本 |
| `添加精准问答#你好#你好呀#Y@` | 强制带艾特 |
| `添加延时精准问答#晚安#好梦#60#N@` | 延迟 60 秒 + 强制纯文本 |
| `添加延时毫秒精准问答#上号#开黑#5000#Y@` | 延迟 5000 毫秒 + 强制带艾特 |

> **提示**：`#N@` / `#Y@` 后缀会被解析器剥离，**不会** 出现在答案内容里。

## 添加规则

- 格式：`添加…问答#问题#答案`；答案可为空字符串，但须 **另附图片**，否则会提示答案不能为空。
- **延时问答** 格式：`添加延时…问答#问题#答案#秒数` 或 `添加延时毫秒…问答#问题#答案#毫秒数`。
- 同一范围、同一类型下，**问题已存在则不能覆盖**；请先删除再添加。
- 菜单蓝字点「设置…撤回时间#120」时，填入框默认是 `#115`（可改）。

## 匹配顺序

**群聊**：先查 **全局**，再查 **本群**。
**私聊**：先查 **全局**，再查 **私聊**。

每个范围内，命中优先级：

1. **精准** 普通
2. **模糊** 普通
3. **延时精准**（秒）
4. **延时模糊**（秒）
5. **延时毫秒精准**
6. **延时毫秒模糊**

命中后：

- 若为 **延时类**，先 `setTimeout(delay)` 等待，再发送
- 若为 **普通类**，立即发送

回复一条（或带图的）Markdown，顶部一般为：

```text
<@用户 openid>
答案内容…
> 响应用时: xxms
```

（如果该条答案或所在范围设置为 **纯文本**，则只输出答案内容，没有艾特，没有响应用时）

## 答案撤回

菜单蓝字：`设置本群/全局/私聊答案撤回时间#120`（展示）；点进去默认填 `#115`。

| 秒数 | 含义 |
|------|------|
| `0`（默认 / 未配置） | 不撤回 |
| `1`～`600` | 成功输出后倒计时撤回 **本次机器人发出的答案类消息** |
| 缺参、非整数、超出 0～600 | 警告，**不写盘** |

会按撤回时间处理的输出：

- 正式命中答复（用 **命中词库** 对应范围的秒数：全局 / 本群 / 私聊）
- 问答词列表、添加成功后的预览（用 **当前聊天场景**：群→本群秒数，私聊→私聊秒数）

不会自动撤的：菜单本身、设置成功提示、超范围警告、删除 / 清空确认等。

说明：官方对机器人自发言消息的可撤窗口往往约 2 分钟；配到更长时，超时失败只记日志，不打扰群聊。

## 常见问题

**发了管理指令没反应？**
多半无权限，插件故意静默。核对配置主人 openid，或确认你是本群群主 / 管理员。若你是普通成员，可改用 `问答菜单` 查看使用说明。

**加了问答却命中不了？**
检查是精准还是模糊；精准要求全文一致（去掉 @ 后）。全局是否先命中了别的词。

**列表里没有某类型？**
该类型为空则不显示。普通用户只能看到本群问答。

**想改已有答案？**
先删除对应问题，再添加。

**延时问答添加后没反应？**
请确认：
1. 添加时返回的提示是否显示「已新增【本群延时…问答】」
2. 发送 `问答词列表` 是否能看到对应条目
3. 是否在正确的群聊中操作（延时问答仅限群聊）
4. 命令的秒数 / 毫秒数是否在合法范围内（秒 1～60，毫秒 1～60000）

**单个答案的 `#N@` 后缀显示在了答案内容里？**
请确认插件版本为 v1.1.0 或更高；旧版本不支持该功能。

**回复模式切换后不生效？**
优先级顺序：单条答案后缀 > 本群 / 私聊模式 > 全局模式。请检查是否存在更高优先级的覆盖。
